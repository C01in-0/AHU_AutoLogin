# AHU AutoLogin（安大校园网无感连网引擎）

**作者：Colin · 版本：v1.2 · 平台：Windows**

告别每天手动点校园网认证。安装一次，插网线、开机或登录 Windows 时自动尝试连网。

- **轻量**：事件触发，用完即退，没有常驻进程。
- **无感**：后台静默认证，不弹黑框。
- **省事**：自带运行环境，无需安装 Python。
- **兼容 TUN**：探测取到虚拟网卡地址时，回退查找校园网地址，并为本次请求指定接口。

## 🟢 开箱即用

1. 完整解压 `AHU_AutoLogin_v1.2.zip` 到固定文件夹。
2. 右键 `01_一键安装（右键管理员运行）.bat`，选择“以管理员身份运行”。
3. 按提示输入校园网账号和密码，完成后即可关闭安装窗口。

以后交给任务计划自动运行，保持安装目录位置不变即可。只想快速上手，看旁边的 TXT 就够了。

## ❓ 常见问题 Q&A

### Q1：周末回家插上家里网线，或者连别人手机热点，这个工具会发癫吗？

一般不用管它。网络变化可能唤醒程序；如果没有匹配的校园网地址，或认证网关不可达，短暂尝试后就会退出，不会一直挂在后台。

### Q2：网已经通了，为什么校园网登录网页有时候还是会弹出来？

Windows 自带的联网检测有时比脚本更急：认证还没完成，它就先弹出了登录页。等你看到页面时，后台可能已经连上了。外网能正常访问的话，关掉页面即可。

### Q3：日志里的 ret_code=2 是失败吗？

在项目适配的 Portal 响应中，`result=0、ret_code=2` 表示当前 IP 已经在线。新版把它记为 `already_online`，属于正常结果。

新版日志看这几个状态就够了：

- `authenticated`：认证成功。
- `already_online`：已经在线，无需重复登录。
- `authentication_rejected`：认证被拒绝，先检查账号、密码和运营商后缀。

### Q4：插网线后要等几秒才连上，正常吗？

正常。网线刚插上时，地址分配和路由更新需要一点时间。程序会短暂等待，任务计划也保留了延迟补偿，给网络一个准备好的机会。

### Q5：微信能用，浏览器却打不开网页，关闭系统代理后立刻正常？

这通常是系统代理残留。比如代理软件已经退出，浏览器却还在把请求交给 `127.0.0.1:7890`。

如果你还要使用代理，先确认代理客户端正在运行；如果已经不用了，到 Windows“设置 → 网络和 Internet → 代理”关闭手动代理。本工具不会替你切换日常代理设置。

### Q6：能否彻底阻止校园网认证网页弹出？

本工具负责自动认证，弹不弹网页由 Windows 的联网检测决定。一般认证完成后就可以正常使用，不需要为了消除弹窗去改系统设置。

### Q7：怎么卸载？

右键根目录的 `02_卸载（右键管理员运行）.bat`，选择“以管理员身份运行”。它会删除本工具的五个认证任务，完成后再按需删除整个文件夹即可。

### Q8：开着 Clash / FlClash 的 TUN 模式还能用吗？

v1.2 针对旧版取到 `198.18.0.1` 后无法继续认证的问题做了调整：原探测结果无效时，会查询网卡、筛选校园网地址，并绑定本次认证连接的源 IP 和接口。

普通情况下无需额外设置。如果电脑上有多个符合条件的校园网地址，日志会提示接口配置有歧义。这时用 PowerShell 执行：

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
    Select-Object InterfaceAlias, InterfaceIndex, IPAddress
```

找到真实校园网地址对应的 `InterfaceIndex`，在 `程序文件/.env` 中添加 `CAMPUS_INTERFACE_INDEX=实际编号` 即可。不要把 `198.18.` 加进校园网地址配置。

### Q9：升级需要重新输入账号密码吗？密码改了怎么办？

通常不用。把新版解压到新文件夹后运行安装器，它会尝试沿用旧任务目录里的配置；已经存在的配置也会保留。

如果没有自动找到旧配置，把旧 `.env` 复制到新版的 `程序文件` 文件夹即可。密码变更时，用记事本修改其中的 `CAMPUS_PASSWORD`，然后运行 `程序文件/login.exe` 认证一次。

### Q10：装好了还是没联网，先看哪里？

先打开 `程序文件/autologin.log`，看最近一次运行的结果：

- `missing_account_or_password`：账号或密码没有填写完整。
- `no_campus_ip`：暂时没找到符合配置的校园网地址。
- `network_error`：认证请求未能完成，检查校园网连接和网关是否可达。
- `authentication_rejected`：服务端拒绝认证，检查账号大小写、密码、运营商后缀及账号状态。

反馈问题时附上报错状态和使用环境即可，账号密码文件 `.env` 留在本地。

### Q11：有保活吗？需要一直运行吗？

不需要一直运行。除了网络事件、开机和登录触发，还保留每周一 09:00 的一次兜底认证。平时没有本工具的常驻进程，也不会循环 ping 外网。

## 🛠 二次开发

使用配套源码包和 Python 3.12：

```powershell
python -m pip install -r requirements-build.txt
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

脚本会运行测试、生成单文件 `login.exe`，并把使用包和源码包放到 `dist`。
